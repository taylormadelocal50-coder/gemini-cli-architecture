# MESH Connection Flow

MESH evaluates a relationship through four stages: **match**, **exchange**, **state**, and **harmony**. The resulting action is to accept, alter, or isolate the relationship.

```text
              ┌──────────────┐
              │   SYSTEM A   │
              └──────┬───────┘
                     │
                  MATCH
                     │
              ┌──────▼───────┐
              │     MESH     │
              │              │
              │ What are we  │
              │ connecting?  │
              └──────┬───────┘
                     │
                  EXCHANGE
                     │
              ┌──────▼───────┐
              │     MESH     │
              │              │
              │ What changes │
              │ through it?  │
              └──────┬───────┘
                     │
                   STATE
                     │
              ┌──────▼───────┐
              │     MESH     │
              │              │
              │ Is this still│
              │ the intended │
              │ relationship?│
              └──────┬───────┘
                     │
                  HARMONY
                     │
                     ▼
              ACCEPT / ALTER
                 / ISOLATE
```

## Interpretation

- **Match** identifies the systems or entities being connected.
- **Exchange** identifies what changes across the connection.
- **State** checks whether the relationship remains intended.
- **Harmony** determines whether to accept, alter, or isolate the relationship.
