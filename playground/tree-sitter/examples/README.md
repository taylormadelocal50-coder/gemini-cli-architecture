# Examples

The fixture files in `../fixtures/` are intentionally small so query captures are easy to inspect. Use the matching language grammar with the query files in `../queries/`.

Example pairings:

- `../fixtures/javascript/basic.js` with `../queries/javascript/functions.scm`
- `../fixtures/typescript/basic.ts` with `../queries/typescript/types.scm`

Keep examples deterministic and avoid committing generated parser output or downloaded archives.
