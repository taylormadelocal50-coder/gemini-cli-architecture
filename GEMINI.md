# Gemini Project

Welcome to the Gemini Project repository. This project is structured to organize source code and notes systematically.

## Directory Structure

- `code/`: Contains all project source code, scripts, and implementation files.
- `notes/`: Contains documentation, research notes, planning, and other reference materials.
- `GEMINI.md`: This file, containing shared project instructions, guidelines, and conventions.

## General Conventions

- **Code style**: Follow idiomatic practices for any languages used within the `code/` directory.
- **Documentation**: Keep research and reference materials up to date in the `notes/` directory.
- **Collaboration**: Document workflows, architecture decisions, and important scripts in this instructions file.
