# MESH State Vector

MESH represents state as a multidimensional vector spanning temporal, energetic, social, coherence, decision, and longevity dimensions.

The diagram for this model will be added in a later change.

```text
MESH_STATE {
    temporal:
        start
        duration
        sequence_position
        recovery_interval

    energy:
        input
        expenditure
        replenishment
        net_change

    social:
        cooperation
        reciprocity
        altruism
        externality

    coherence:
        internal_consistency
        system_harmony
        contradiction
        instability

    decision:
        available_choices
        predicted_outcomes
        reversibility
        uncertainty

    longevity:
        immediate_effect
        persistent_effect
        cumulative_effect
}
```

## Dimensions

| Dimension | State variables |
| --- | --- |
| Temporal | Start, duration, sequence position, and recovery interval |
| Energy | Input, expenditure, replenishment, and net change |
| Social | Cooperation, reciprocity, altruism, and externality |
| Coherence | Internal consistency, system harmony, contradiction, and instability |
| Decision | Available choices, predicted outcomes, reversibility, and uncertainty |
| Longevity | Immediate, persistent, and cumulative effects |
